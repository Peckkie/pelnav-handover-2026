# pelnav-handover-2026

ไฟล์ส่งมอบเว็บมาร์กจุด PelNav

- `test_package/` ภาพทดสอบ (ไม่มีข้อมูลผู้ป่วย) ใช้ลองหลังติดตั้งเสร็จ
- `linux/` วิธีติดตั้งบนเครื่องแล็บที่เป็น Linux + docker (คู่มือเดิมเป็น Windows)
- `คู่มือใช้งาน-PelNav-แพทย์.pdf` / `.docx` คู่มือใช้งานเว็บสำหรับหมอ step by step (ภาพประกอบเป็นภาพทดสอบ)

ภาพเคสจริง (orig_package) มีชื่อ/HN ผู้ป่วย ห้ามเอาขึ้น repo นี้
